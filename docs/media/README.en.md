These assets support the repository's README presentation. The website keeps its existing runtime assets and build entries.

| File                                                | Source and purpose                                                                                                                                                                                                         |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `readme-language-zh.svg` / `readme-language-en.svg` | Chinese and English reading links at the top of each README, using the CirCure wordmark palette. Static SVGs with no external fonts, scripts, or dependencies.                                                             |
| `readme-visit-wiki-zh.svg` / `readme-visit-wiki-en.svg` | Official Wiki primary buttons for the Chinese and English READMEs, using the language buttons' brand purple. Static SVGs with no scripts or external resources; the surrounding link handles navigation. |
| `readme-team-marks.svg`                             | Original JLU-FBH crest and iGEM mark from `src/assets/jlu-fbh-crest.png` and `src/assets/partners/sponsor-igem.png`.                                                                                                       |

| `wiki-circrna.jpg`                                  | Captured on 2026-10-22 from the “Why circular RNA?” scene on the [official Wiki](https://2026.igem.wiki/jlu-fbh/), at 1265 × 712. Original browser screenshot pixels are retained. The scene is a conceptual illustration. |

Both README languages share these images. Use real pages or existing project assets for updates and maintain captions and provenance together.

Logo panels use SVG only for layout and a white reading surface. Original files are embedded byte for byte, preserving their colors, shapes, and proportions in both light and dark themes. Mark names are also provided as README text.
