# 内容原稿与来源资料

这里保存团队提供的正文原稿、图片与附件、设计说明和其他来源文件。网页实际呈现在 `src/data/` 与对应 feature 组件中。

| 目录 | 内容范围 |
| --- | --- |
| `team/` | 团队页面来源 |
| `project/` | 项目介绍、工程、结果与贡献等资料 |
| `wetlab/` | 湿实验页面、实验方案与测量等资料 |
| `drylab/` | 模型、软件和硬件等资料 |
| `engagement/` | 社会实践、教育、可持续发展等资料 |

[Wiki 设计与排版规范](Wiki-设计与排版规范.md) 保留原路径；它与根目录的[页面架构规范](../WIKI_ARCHITECTURE_SPEC.md)配合使用。

部分导入、素材转换和内容核对脚本直接读取这里的文件，历史目录中包含原有大小写和拼写。整理时先查脚本与资产目录的引用，再决定是否更名；本轮保留原有文件与子目录。

原稿与网页数据不会自动同步。变更科学表述、公式、参数、单位或结论时，应由内容负责人确认，再同步对应网页并运行适用的核对脚本。脚本清单见 [scripts/README.md](../scripts/README.md)。

Software 的另一份原根目录参考稿现位于 [docs/content/software-source.md](../docs/content/software-source.md)。不要仅根据文件名判断其与当前网页、定稿目录之间的版本关系。

上传副本与清单统一收纳在 [delivery/](../delivery/README.md)，本目录保留内容来源。
