# Manuscripts and source materials

[简体中文](README.md) | English

This directory retains team-authored manuscripts, images, attachments, design notes, and other source material. The website presentation lives in `src/data/` and the relevant feature components.

| Directory     | Scope                                                                 |
| ------------- | --------------------------------------------------------------------- |
| `team/`       | Team page sources                                                     |
| `project/`    | Description, engineering, results, contribution, and related material |
| `wetlab/`     | Wet-lab pages, protocols, and measurement                             |
| `drylab/`     | Models, software, and hardware                                        |
| `engagement/` | Human Practices, education, and sustainability                        |

The [design and typography specification](Wiki-设计与排版规范.md) (Chinese) works alongside the root [page architecture specification](../WIKI_ARCHITECTURE_SPEC.md) (Chinese).

Some importers, asset converters, and content checks read these paths directly. Existing names retain their original spelling and case. Update script and asset-catalog references when renaming directories or files.

Manuscripts and page data are maintained separately. Scientific wording, formulas, parameters, units, or conclusions should be reviewed by the content owner before updating the website and running relevant checks. See [scripts/README.en.md](../scripts/README.en.md).

Another Software reference manuscript lives in [docs/content/software-source.md](../docs/content/software-source.md). Review its provenance before treating it as the same version as current page data or the final manuscript directory.

Upload copies and manifests are indexed in [delivery/](../delivery/README.en.md). Manuscripts and source attachments retain their original content and language.
