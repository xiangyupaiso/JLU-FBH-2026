01 / Executive Summary

品牌视觉基因

CirCure 的视觉系统是「人文科学编辑风」（Humanist Scientific Editorial）——它像一份被精心编辑的科学出版物，而非生物技术仪表盘或医院门户。三种视觉角色并存：编辑式衬线标题承载叙事、海军蓝结构表面承载科学证据、暖纸色与粉色丝线承载人文关怀。

系统的核心张力来自克制：粉色（Pink Thread）只用于连接、活跃路径与丝带结，从不填充整面；海军蓝是结构色而非全页底色；留白本身即是层级的一部分。所有运动遵循同一条 cubic-bezier(.22,1,.36,1) 缓动曲线，可逆且无过冲，让滚动叙事像翻阅一本可以来回翻动的书。

字体因 iGEM 禁用 CDN 的规则完全采用系统字体栈：Iowan/Baskerville 衬线负责标题与人文陈述，系统无衬线负责数据与控件，等宽字体仅用于序列、时间戳与实验状态。这份规范将上述基因转译为 Figma 可消费的变量、样式与 Auto Layout 参数。

三条不可违背的原则： ① 粉色必须传达「连接」而非装饰；② 海军蓝是结构色，不做全页铺底；③ 组件在不带动画时仍须可被理解。新增组件前需通过 STYLE_GUIDE 的五项检验。
02 / Color Palette

色彩系统

色彩被严格分配角色：暖纸色是基底，海军蓝是结构，粉色是连接，珊瑚/金/灰蓝仅作数据分类。语义色由既有品牌色映射而来，不引入新色相。

05 / Visual Style

视觉风格与品牌调性

风格定位为「人文科学编辑风」——介于编辑杂志与科学出版物之间。它刻意区别于生物技术仪表盘、医院门户或装饰性宣传页。

Style Classification — 风格分类

  • 编辑式留白：非对称留白承载层级，答案优先的内容结构。
  • 科学结构：海军蓝表面、开放圆环、节点连线、可逆滚动联动。
  • 人文温度：暖纸色表面、粉色丝线、经同意的声音或刻意留空的座位。

Visual Texture — 视觉纹理

  • 边框：以 1px 细线为主（rgba(27,23,25,.18)），海军蓝区段用 rgba(252,248,241,.12)。
  • 渐变：仅用于下拉面板背景与 Hero 遮罩，不用于通用卡片。
  • 毛玻璃：头部 backdrop-filter: blur(16px)，下拉面板 blur(18px)。
  • 图标：线描（line）为主，Pink Thread 丝带结为唯一品牌符号，须引用共享 SVG #circure-ribbon-knot，禁止在每张卡片重复水印化。

Motion — 运动规则

  • 所有运动共用 cubic-bezier(.22,1,.36,1)，可逆且无过冲。
  • 悬停位移限制在 4–5px，丝线引导用临界阻尼弹簧。
  • 每屏只允许一个主导表达性动画，其余运动仅揭示状态或方向。
  • 禁用持续浮动、脉冲、旋转等吸引注意力的循环。
  • prefers-reduced-motion 必须保留全部内容与身份。
