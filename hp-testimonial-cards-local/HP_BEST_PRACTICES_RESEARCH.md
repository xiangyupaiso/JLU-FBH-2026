# CirCure HP 优化研究：2022–2025 Best Integrated Human Practices

## 研究范围

本次研究核对了 iGEM 官方 2022、2023、2024、2025 Competition Results 中 Best Integrated Human Practices 的 Winner 与 Nominee，并重点审阅了与 CirCure 更相关的医疗、技术平台和高完成度 Winner 页面。页面优化以官方评审问题为第一依据，以历年高分项目的共同做法为第二依据。

## 官方评审核心

Best Integrated Human Practices 重点回答五件事：

1. HP 是否贯穿项目，而不是集中在开头或结尾。
2. HP 是否真正改变项目目的、设计或执行。
3. 项目是否能成为其他团队可复用的启发性案例。
4. 方法、背景、理由与既有工作是否被周到地记录。
5. 是否纳入了真正不同的利益相关者观点。

## 跨四年共同规律

### 1. 强项目展示“决策”，弱项目展示“活动”

决定项目目的、构建、实验、模型、硬件、监管路线、目标用户或部署位置的改变，比访谈数量更有说服力。

### 2. 真实冲突比顺滑背书更可信

获奖项目会展示被放弃的方向、价值冲突、不可行条件、反对观点与未解决问题。整页都是正面引语会显得像营销。

### 3. 框架只有在产生可追踪输出时才有价值

AREA、Gibbs、STIR、Value-Sensitive Design、Mendelow、4A、RARE 本身不会获奖。真正有价值的是它们能生成 decision record、design requirement、changed artifact、return loop 和 limitation。

### 4. 医疗项目必须把伦理与数据治理放进工程过程

患者/照护者参与、知情同意、隐私层级、机构审批、数据保存、引语使用边界、过度承诺风险不能只出现在 Safety 页尾部。

### 5. 可复用贡献是拉开差距的关键

优秀页面不仅说明“我们做了什么”，还提供访谈协议、利益相关者映射、分析方法、决策表、回访清单或复用框架，让下一届团队能直接采用。

## 对当前 CirCure 页面诊断

### 已经很强

- “The world changed CirCure” 是清晰、可记忆且符合 HP 本质的主张。
- stakeholder impact wall 用视觉方式表达 input → change，比活动相册有效。
- evidence timeline 已包含 why / heard / change / evidence / follow-up，是正确的数据模型。
- dossier 明确覆盖临床、技术、伦理、公众沟通、实施与 unknowns。
- “主动放弃机制”和“回访验证”是评委非常重视的高价值节点。

### 原版主要缺口

- 评委仍需在 10 张横向卡、8 个时间点和 5 个 dossier 章节之间自行拼出最重要的改变。
- evidence-link 外观像链接但实际不是链接，证据可审计性不足。
- 缺少集中的 before → signal → decision → primary proof 总表。
- 访谈选择、 consent、分析、冲突处理与 bias 没有形成一个可复用的方法区。
- 大量数字、引语和 evidence code 仍是原型占位内容；若不替换会直接削弱可信度。

## 本轮页面优化决策

1. 保留 Purpose / Design / Execution / Governance / Implementation 五层 Decision Proof，但将其后移到完整正文，避免首屏信息过密。
2. 将 impact card 的证据文字改为真实锚点链接，直接跳到对应 timeline record。
3. 新增 Method, Ethics, and Limits，明确 select / engage / decide / return 的方法与风险。
4. 新增 `HP_FIELD_KIT.md`，提供可复用的 stakeholder map、engagement protocol、consent tier、decision ledger、conflict rule、return-loop checklist 和 publication gate。
5. 保留现有视觉与故事结构，避免为“更丰富”继续增加无效卡片。

## 发布前最高优先级

1. 用真实、经同意的原始材料替换全部日期、人数、比例、引语、人物角色和 evidence code。
2. 给每个 evidence code 提供真实页面、PDF 或公开记录，并区分公开与受限证据。
3. 至少完整展示两个项目级改变：原始版本、触发证据、团队决策、改变后的技术产物、回访结果。
4. 明确谁没有被纳入、哪些患者/临床/监管观点不能代表整体，以及这些缺口限制了哪些结论。
5. 把 HP 改变同步回 Project、Design、Model、Wet Lab、Safety 和 Proposed Implementation 页面，形成跨页双向链接。
